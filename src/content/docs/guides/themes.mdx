Themes are design tokens, not forks: CSS variables in `shared/styles/`, one file per theme. Rebranding a whole product means editing one file.

## In the box

Three themes (dark, light, alt). Starter buyers pick any 3, Pro any 10, Pro+ gets all present and future themes. Picks attach to the license and travel with upgrades.

## Rules

- Token architecture only — never hardcode colors in components.
- Main site shows 1 theme; the gallery sells the rest.
- Attribution component (`MadeWithStartplate`) stays in the footer per tier: Starter must keep it, Pro optional, Pro+ white-label.
