# Startplate — frozen snapshot

This ZIP is a **frozen snapshot**, not the product. The product lives in your
private GitHub repo — `git pull` there for updates.

## Start in 3 commands

```bash
npm install
cp .env.example .env   # then fill it (see docs: /reference/env-vars)
npm run dev
```

Full guide: Starlight docs included under `src/content/docs`
(start at `quickstart`), or read them hosted with your deployment.

## What's inside

Template source + themes + docs + `.env.example` + `LICENSE.txt` + this file.
No `node_modules`, no secrets, no `.env` — install and configure yourself.
